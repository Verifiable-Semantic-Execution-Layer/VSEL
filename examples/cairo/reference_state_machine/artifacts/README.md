# Artifact Hash Manifest

`HASHES.md` records local build outputs after:

```sh
scarb clean
scarb build
snforge test
cd executable
scarb clean
scarb prove --execute --arguments-file inputs/valid_transition.json
scarb verify --execution-id <execution-id-produced-by-prove>
```

The manifest records SHA-256 hashes for:

- `Scarb.toml`
- `semantic_core/src/lib.cairo`
- `src/reference_contract.cairo`
- `tests/test_reference_state_machine.cairo`
- generated Sierra contract class JSON
- generated CASM compiled contract class JSON
- executable proof JSON generated by Scarb/Stwo

The manifest is evidence of local reproducibility for this example only. It is not a verifier input and does not imply semantic validity by itself.
